# Travel Journal

A responsive travel journal built from scratch with HTML, CSS and JavaScript.

This project documents four trips from my gap year: Edinburgh, Budapest, Fez and New York. It was created as a personal project to practice front-end development and gradually introduce interactivity with JavaScript.

## Features

- Semantic HTML structure
- Responsive design
- Flexbox navigation
- CSS pseudo-classes and pseudo-elements
- Custom image cropping with `object-fit` and `object-position`
- Smooth navigation between city sections
- Back-to-top button displayed based on scroll position
- Interactive image galleries for each city
- Dynamic main image replacement when clicking on thumbnails
- Custom image positioning depending on the selected picture
- Visual indication of the active thumbnail

## Built With

- HTML5
- CSS3
- JavaScript

## What I Learned

This project allowed me to strengthen my HTML and CSS skills while getting my first hands-on experience with JavaScript.

I practiced selecting and manipulating HTML elements with JavaScript, responding to user interactions with event listeners, working with multiple elements using `forEach()`, modifying CSS classes with `classList`, using conditions and dynamically changing image sources and styles.

It also helped me better understand how HTML, CSS and JavaScript work together to create an interactive web page.
