# Travel Journal

A responsive travel journal built from scratch with HTML and CSS.

This project documents four trips from my gap year: Edinburgh, Budapest, Fez and New York.

## Features

- Semantic HTML structure
- Responsive design
- Flexbox navigation
- CSS pseudo-classes and pseudo-elements
- Custom image cropping with `object-fit` and `object-position`

## Built with

- HTML5
- CSS3
